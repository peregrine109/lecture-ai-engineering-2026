### 基礎：検索を必須にする指示の変更

`app/agent.py` の INSTRUCTIONS から、次の1行を削除した条件を用意した。

> 用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。

元の条件を baseline、変更後を basic とし、どちらにも「LoRAとQLoRAの違いは？」という同じ質問を送った。ツールの実装とdocstringは変更せず、同じモデルを使い、会話履歴を引き継がずに実行した。

| 比較項目 | 変更前 | 変更後 |
|---|---|---|
| search_glossary の呼び出し回数 | 2回 | 2回 |
| 引数（記録順） | query="LoRA"、query="QLoRA" | query="LoRA"、query="QLoRA" |
| get_lecture_summary の呼び出し回数 | 0回 | 0回 |
| 記録内のモデル応答数 | 2回 | 2回 |
| 回答で示した関連講義 | 第2回 | 第2回 |

変更前は「講座の用語集によると」と出典を明示し、LoRAを2つの小さな低ランク行列の積で表すPEFT手法と説明した。変更後は量子化の有無を先に示し、「通常は16ビットなどの精度」という補足を加えていた。どちらも、LoRAはベースの重みを固定して小さな行列を学習し、QLoRAはベースの重みを量子化してメモリを節約するという要点を説明していた。

今回、ツールの名前・回数・引数は変わらず、回答の構成や補足に違いが見られた。INSTRUCTIONSの1行を削除しても、search_glossaryのdocstringには「答える前に使うこと」という指示が残るため、検索が継続した一因として考えられる。ただし各条件1回だけの比較なので、回答の違いを指示変更の効果と断定することはできない。また、変更後の「通常は16ビット」という補足は検索結果には含まれておらず、ツールを使用していても回答の全記述が検索結果だけに基づくわけではないと分かった。

### 実装：承認付きの学習メモ保存

`app/tools.py` に `save_learning_log(title, content)` を追加した。保存先は `learning_log/` とし、日時とUUIDを使ったファイル名でMarkdownを保存する。モデルには保存パスを指定させず、既存ファイルを上書きしないようにした。

エージェントには `requires_approval=True` で登録し、出力型を `[str, DeferredToolRequests]` にした。保存要求が発生するとCLIでタイトルと本文を表示して一時停止する。`y` または `yes` の場合だけ承認し、それ以外や空入力・EOFは拒否する。承認結果を `DeferredToolResults` に入れ、それまでのメッセージ履歴と一緒に渡して処理を再開する。

同じ依頼を2回送って、承認と拒否を比較した。

- タイトル：承認フローの学習
- 本文：書き込みツールは人が承認してから実行する。

| 比較項目 | 承認した実行 | 拒否した実行 |
|---|---|---|
| 保存ツールの呼び出し要求 | 1回 | 1回 |
| approved | true | false |
| ツール結果の outcome | success | denied |
| 最終回答 | 学習メモを保存しました | 保存が拒否されたため、保存処理を行いませんでした |

承認時には保存先を含む成功結果が記録され、そのパスと一致するMarkdownが結果ZIPに含まれていた。内容も指定したタイトル・本文と一致していた。拒否時はツール結果が `The tool call was denied.` となり、再度の保存要求はなかった。ZIPに含まれる学習メモは承認時の1件だけで、拒否時の記録とも整合していた。

拒否時にもツールの呼び出し要求は1回記録されるが、それは保存関数の実行成功を意味しない。モデルによる要求と、プログラムが承認後に実行する処理を区別する必要がある。自然言語で「勝手に保存しないで」と指示するだけでなく、実行側で承認を必須にすることの意味を理解できた。

コード作成時には、AIの作業環境でAPI不要のテスト9件が成功したとの報告を受けた。これは今回の実Geminiの実行結果とは別の検証である。

### 気づき・今後確かめたいこと

最終回答だけでは、根拠を検索したか、保存操作が本当に実行されたかは分からない。traceでツール名・引数・結果まで確認することが重要だと分かった。今後は複数の質問と繰り返し実行で比較し、INSTRUCTIONSとdocstringそれぞれの影響を調べたい。承認機能についても、複数の保存要求が同時に出る場合の動作を確認したい。
